# CogniFlow — AI architectures, brought to life (personal project)

Written by Prashobh Paul for the Knowledge Fabric, November 2026.

## What it is
CogniFlow makes architecture diagrams with motion and animation, the kind my clients
prefer over static diagrams I used to draw in draw.io.

## Why I built it
Even with Claude it took a lot of prompting to get animated architecture diagrams, so I
built CogniFlow and connected it to my Claude to make architecture design work easier. I
always build tools that make my own work easier.
